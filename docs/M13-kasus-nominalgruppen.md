# M13 — G02 Kasus und Nominalgruppen im Kontext

Six originally authored C1/C2 three-paragraph fictional drafts contain 18 *deliberately malformed* nominal phrases, each source-anchored to a stable paragraph and labeled with a specific case governor, role, authored correction and grammatical explanation. Covers governed dative/accusative, n-declension, mixed inflection, adjective agreement, substantivized adjectives, genitive plurals and chains. Source rights are original draft; no third-party text, audio, official CEFR grading or independent editorial approval.

M13 is distinct from the original M02 isolated article/adjective slot grader and M11 document-level argumentation editing. Learners identify case governance, choose syntactic case, write a corrected complete noun phrase and explain why. Author solutions display *after* each ungraded saved repair. The independent final transfer requires original sentences, a source paragraph, a case-government rationale and supports append-only revisions with the existing word-level comparison. A mistaken learner choice remains stored as evidence, not a correctness score.

Records reuse the original `productionEntries` IndexedDB store, original CAS semantics and backup v3. The first `original` permanently contains repair + justification, `decisionId` anchors r1|role|p1, and later `REPAIR:rN`, `TRANSFER`, `REWRITE` revisions preserve source ID/version and full history. The archive compares only adjacent free-writing revisions; not unlike repair responses. M13 is separately registered in the original source manifest, draft content validator and independent human editorial worklist (24 unapproved dossiers). Existing M01–M12 IDs, all eight IndexedDB stores, scheduler, grader, review, diagnostics, Artikelwerk and original learner data remain untouched.

Acceptance: source/content validation; Node domain, backup v3, ungraded evidence and editorial inventory tests; Chromium desktop and mobile with staged repair, explanation, competing-tab CAS rejection, transfer, revision, Progress, Archive, return and reload. No release, merge, production write or deployment.
