# M09 — Sprachmittlung und differenzierte Argumentation

- Four separate M09 learning briefs mapped to original fictional G09 reading passages SG-R09-001 through SG-R09-004. No third-party source text, audio or attribution claims are introduced.
- The learner selects a source paragraph and recipient, saves their first interpretation once, then writes multiple audience-sensitive adaptations and counterarguments with an explicit uncertainty/limitation note and selected paragraph evidence for each.
- G13 is ungraded; model examples, CEFR certification, editorial approval and automatic linguistic feedback are never asserted.
- Source identity/version are held in the original `ProductionEntry.sourceId/itemId/itemVersion`; first recipient and paragraph evidence in immutable `decisionId` as `audience|paragraph`. Each append-only revision records stage via `questionId`, evidence paragraph via `paragraphId`, uncertainty via `reflection`, and explicit self-checked source criteria via `selfChecks`.
- Original IndexedDB `productionEntries` CAS writer rejects stale/overwriting changes; no schema, stores, backup v3, scheduler, grade, diagnostic or mission change.
- Native Today, G13 Curriculum, Progress, Writing Archive search and source-return navigation. Existing G09 reading remains independently accessible.
- Content is `DEMO_ONLY` and authored as original fictional practice prompts, not licensed external material.
