# M50 — Meaningful practice when original topic contexts are exhausted (development only)

## Verified source audit
M49 correctly refuses to invent a fourth unseen same-topic exercise after all currently authored tasks have been answered. M48's independent 24-hour transfer cannot be re-run on a seen task without misleading evidence. M49's earlier-error reconstruction is useful after a specific three-step failure, but not for every exhausted objective topic. The actual existing DEMO_ONLY exercise fixtures include two or more differently authored accepted forms for many same-topic groups, e.g. G01.GENUS Gesellschaft ("die Befugnis" versus "das Argument"). Such concrete contrasts permit a high-effort **retrieval-plus-explanation** task without authoring new content or pretending it is novel.

## Source-valid implementation
- Read-only \`exhaustedContrastPlans\` uses the exact authored current-version first encounters, the authoritative Error Archive cluster, current \`Exercise\` fixtures and review cards. It qualifies only **unresolved** same-mode/same-skill/same-author-topic groups where **all** current active exercises have actually been attempted at the exact available versions; at least one first attempt is uncertain; there are at least two different accepted author forms in the actual slots. Changed/withdrawn/missing versions and groups without a real contrast fail closed.
- The existing Fehlerarchiv offers **Bekannte Aufgaben kontrastieren**. A learner must **blindly re-enter both familiar forms**, then independently explain the anticipated difference before original answers, author draft keys, and context-specific explanations are revealed. The learner compares to the exact original saved first responses; \`gradeAnswer\` compares the blind forms locally against *existing* author keys but never saves a new \`Attempt\` or a mastery score.
- After seeing the originals, the learner must write a revised rule, a new third example and a justification for the predicted form. **Own examples are not linguistically verified or graded.** Length/difference guards prevent empty submissions but cannot validate correctness. These drafts remain ephemeral under the M35 schema/backup/CAS freeze, with explicit UI disclosure.
- If an actually due, exact-version objective card from that topic exists, a guarded route launches **the existing real review scheduler with its unchanged CAS**, requiring normal submitted answers for a durable review event. Otherwise, a guarded route opens an existing source-writing workshop in the **same G-domain** (G01 reference, G02 case tracing, G03 valency, G04 relation, G05 modality, G06 definitions, G07 phraseology). That source studio is clearly not presented as another authored same-topic task or validated transfer.
- All item prompts, solutions, first attempts, versions, and stored reviews remain unchanged by the contrast reflection itself. No synthetic source, lexical key, CEFR, editing bypass, newly published editorial approval or invented proficiency metric.

## Acceptance / limits
- Pure tests: exhaustive exact current version; no early exhaust while fresh context remains; no error => no remediation; invalid/withdrawn/historical/future fail closed; due current card only; varied accepted forms required; source data not mutated.
- Genuine Chromium at 1280px: fixture three first attempts in G01 Gesellschaft -> no new-context CTA -> cold two-source answers -> reveal original author answers -> corrected rule + original new example + rationale -> existing G01 source studio; original attempts and production count unchanged on reload.
- Genuine Chromium at 360px: same flow with valid due card -> real old-task scheduled review -> original history preserved, exactly one real review event, no invented new-context attempts.
- Full exact-head content/editorial/Node/TS/Vite, Chromium all M01–M50 desktop/mobile, Firefox/WebKit eight-store, offline upgrade/recovery and true two-bundle A→B→A rollback. No merge, release, publication, external review.
- Known limitation: no evidence that a learner-generated third example is linguistically correct or increases retention; if a particular source group lacks genuinely different authored answers, this option is not offered. A durable reflection format requires explicit future data-contract design, not an unapproved store.
